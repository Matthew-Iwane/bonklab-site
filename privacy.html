Privacy policy: Bonk Lab analytics

Last updated: October 25, 2026

What this app is

Bonk Lab analytics is a private tool used only by the owner of the Bonk Lab YouTube channel. It is not offered to the public, and no one else signs in to it.

What data it accesses

With the channel owner's permission, it uses two read-only Google permissions:

  • youtube.readonly: the list of the channel's own videos and their public counts (views, likes, comments).
  • yt-analytics.readonly: the channel's own aggregate analytics, such as average view duration and average percentage viewed per video.

It cannot upload, edit or delete anything. It does not access any other person's channel or data, and it does not collect information about viewers as individuals. YouTube Analytics only provides totals and averages.

How the data is used

The statistics are used only to compare how different kinds of Bonk Lab videos perform, and to decide which kinds to make more often.

Storage and sharing

Per-video statistics are stored in a private GitHub repository controlled by the channel owner. They are not sold, shared with third parties, or used for advertising. Access credentials are stored as encrypted repository secrets.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored statistics can be deleted on request.
